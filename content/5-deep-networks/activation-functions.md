*Lectures 14 and 15 · [[5-deep-networks/index|Deep networks]] · used in [[5-deep-networks/multilayer-perceptrons|MLPs]] and [[5-deep-networks/convolutional-layers|CNNs]] · the sigmoid first appeared in [[3-linear-models/logistic-regression|logistic regression]]*

> [!abstract] In one breath
> An activation function is a fixed, element-wise non-linear function $\sigma$ applied after a linear layer or a convolution. Without it, stacked layers collapse into a single linear layer (or a single convolution). ReLU, $\max\{0,z\}$, is the default: cheap, and its slope is exactly 1 for positive inputs. Sigmoid and tanh **saturate**: their slopes are at most $0.25$ and $1$ and vanish for large $|z|$, so gradients shrink layer after layer. ReLU's weakness is the opposite: a unit whose input is always negative gets zero gradient and never learns again (a **dead ReLU**).

## What it is

An activation acts on each entry separately: for a vector $z$, $\sigma(z) = (\sigma(z_1), \ldots, \sigma(z_n))$. It has no parameters (leaky ReLU's slope $\tau$ is a fixed hyperparameter). Its job is to break linearity:

$$
W_2 W_1 x = (W_2W_1)\,x \quad\text{(one linear map)}, \qquad W_2\,\sigma(W_1 x) \quad\text{(not linear)}.
$$

The same holds for convolutions: two convolutions in a row equal one convolution with a larger kernel, so CNNs put an activation after every convolutional layer too ([[5-deep-networks/convolutional-layers|convolutional layers]]).

| name | $\sigma(z)$ | range | derivative $\sigma'(z)$ | module | function |
|---|---|---|---|---|---|
| ReLU | $\max\{0, z\}$ | $[0, \infty)$ | $1$ if $z > 0$, $0$ if $z < 0$ | [`nn.ReLU`](https://docs.pytorch.org/docs/stable/generated/torch.nn.ReLU.html) | [`F.relu`](https://docs.pytorch.org/docs/stable/generated/torch.nn.functional.relu.html) |
| sigmoid | $\dfrac{1}{1 + e^{-z}}$ | $(0, 1)$ | $\sigma(z)\,(1 - \sigma(z)) \le 0.25$ | [`nn.Sigmoid`](https://docs.pytorch.org/docs/stable/generated/torch.nn.Sigmoid.html) | [`torch.sigmoid`](https://docs.pytorch.org/docs/stable/generated/torch.sigmoid.html) |
| tanh | $\dfrac{e^{z} - e^{-z}}{e^{z} + e^{-z}}$ | $(-1, 1)$ | $1 - \tanh^2(z) \le 1$ | [`nn.Tanh`](https://docs.pytorch.org/docs/stable/generated/torch.nn.Tanh.html) | [`torch.tanh`](https://docs.pytorch.org/docs/stable/generated/torch.tanh.html) |
| leaky ReLU | $z$ if $z \ge 0$, $\tau z$ if $z < 0$ | $(-\infty, \infty)$ | $1$ if $z > 0$, $\tau$ if $z < 0$ | [`nn.LeakyReLU`](https://docs.pytorch.org/docs/stable/generated/torch.nn.LeakyReLU.html) | [`F.leaky_relu`](https://docs.pytorch.org/docs/stable/generated/torch.nn.functional.leaky_relu.html) |

Leaky ReLU's slope is a small positive number; PyTorch calls it `negative_slope` and defaults it to `0.01`. ReLU is not differentiable at exactly $z = 0$; PyTorch uses slope $0$ there. Many more activations are listed under [non-linear activations](https://docs.pytorch.org/docs/stable/nn.html#non-linear-activations-weighted-sum-nonlinearity) in the `torch.nn` docs.

**Useful facts.** $\tanh(z) = 2\,\textrm{sigmoid}(2z) - 1$, so tanh is a rescaled, zero-centered sigmoid. Symmetry: $\textrm{sigmoid}(-z) = 1 - \textrm{sigmoid}(z)$, and tanh is odd, $\tanh(-z) = -\tanh(z)$.

> [!derivation]- Derivation: the sigmoid's derivative
> With $s(z) = (1 + e^{-z})^{-1}$, the chain rule gives
> $$
> s'(z) = \frac{e^{-z}}{(1+e^{-z})^2} = \frac{1}{1+e^{-z}}\cdot\frac{e^{-z}}{1+e^{-z}} = s(z)\,\big(1 - s(z)\big).
> $$
> The product $s(1-s)$ of two numbers that add to 1 is largest when both are $\tfrac12$, i.e. at $z = 0$, where $s'(0) = \tfrac14$. Similarly $\tanh'(z) = 1 - \tanh^2(z)$, which is $1$ at $z = 0$.

## What you should know

- Without a non-linearity, depth adds nothing: stacked linear layers (or convolutions) collapse into one.
- Formulas, ranges and derivatives of ReLU, sigmoid, tanh and leaky ReLU (table above); $\textrm{sigmoid}' = \textrm{sigmoid}\,(1-\textrm{sigmoid})$, $\tanh' = 1 - \tanh^2$.
- **Saturation and vanishing gradients**: sigmoid's slope is at most $0.25$, so backpropagating through $k$ sigmoid layers multiplies the gradient by at most $0.25^k$ ($\approx 10^{-3}$ for $k = 5$, $\approx 10^{-6}$ for $k = 10$), and less still wherever $|z|$ is large.
- **Dead ReLUs**: zero gradient for negative inputs; a unit that is negative for every input never updates again. Leaky ReLU keeps a slope $\tau$ there.
- **Hidden layers** get an activation; the **output layer** usually does not: it returns logits for [`nn.CrossEntropyLoss`](https://docs.pytorch.org/docs/stable/generated/torch.nn.CrossEntropyLoss.html) or [`nn.BCEWithLogitsLoss`](https://docs.pytorch.org/docs/stable/generated/torch.nn.BCEWithLogitsLoss.html) ([[4-pytorch-training/loss-functions|loss functions]]).
- Module form (`nn.ReLU()`, goes in `__init__` or `nn.Sequential`) vs function form (`F.relu(x)`, `torch.sigmoid(x)`, used inside `forward`). Same math, no parameters either way.

## Vanishing gradients and dead units

In [[2-calculus-and-optimization/backpropagation|backpropagation]], the gradient that reaches layer 1 of a deep network is a product with one factor $\sigma'(z)$ per layer it passes through. With sigmoid every such factor is at most $0.25$:

$$
\Big|\frac{\partial L}{\partial z^{(1)}}\Big| \;\lesssim\; \underbrace{0.25\cdot 0.25\cdots 0.25}_{k\text{ layers}}\;\cdot\;(\text{weights}) ,
$$

so early layers learn far more slowly than late ones. Tanh does better near $0$ (slope 1) but saturates just the same for large $|z|$. ReLU passes the gradient through **unchanged** wherever its input is positive, which is a main reason it became the default for deep networks.

ReLU's failure mode is the flat half. If a unit's pre-activation $w^\top x + b$ is negative for every training input (for instance after a large update pushed $b$ far negative), its output and its gradient are zero for every input, so gradient descent can never move $w$ or $b$ again. Leaky ReLU replaces the flat half by a small slope so the unit can recover.

Lecture 15 plots each activation's gradient with autograd. Because `out[i]` depends only on `z[i]`, the gradient of `out.sum()` is the element-wise derivative:

```python
z = torch.linspace(-5, 5, 201, requires_grad=True)
for name, fn in [('sigmoid', torch.sigmoid), ('ReLU', torch.relu)]:
    out = fn(z)
    grad, = torch.autograd.grad(out.sum(), z)  # elementwise derivative
    # plot z.detach() vs out.detach() and grad
```

See [[2-calculus-and-optimization/autograd|autograd]] and [`torch.autograd.grad`](https://docs.pytorch.org/docs/stable/generated/torch.autograd.grad.html).

## Module or function?

```python
import torch.nn as nn
import torch.nn.functional as F

# as modules: inside nn.Sequential or __init__
mlp = nn.Sequential(nn.Linear(784, 128), nn.ReLU(),
                    nn.Linear(128, 10))

# as functions: inside forward
class TwoLayer(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1, self.fc2 = nn.Linear(784, 128), nn.Linear(128, 10)

    def forward(self, x):
        return self.fc2(F.relu(self.fc1(x)))

act = nn.LeakyReLU(negative_slope=0.1)  # slope tau = 0.1
```

Passing the activation in as an argument (`FourLayerMLP(..., activation_fn=nn.Tanh())` in Lecture 14) makes it a one-line experiment to swap ReLU for tanh or sigmoid. One module instance can be reused at every layer because it has no parameters.

## Which activation where

- **Hidden layers of MLPs and CNNs:** ReLU by default; leaky ReLU if dead units are a problem; tanh and sigmoid mainly in older networks and inside recurrent cells, where their bounded ranges are useful ([[5-deep-networks/lstm-and-gru|LSTM and GRU]] gates use sigmoid to produce numbers in $(0,1)$ and tanh for values in $(-1,1)$).
- **Output layer, classification:** none; the loss applies softmax or sigmoid internally. Apply `torch.softmax(logits, dim=1)` or `torch.sigmoid(logit)` only when you want probabilities to report ([[3-linear-models/binary-cross-entropy|binary cross-entropy]], [[3-linear-models/multiclass-logistic-regression|multi-class logistic regression]]).
- **Output layer, regression:** none, so the output can take any real value.

> [!trap] Common mistakes
> - **Leaky ReLU's sign.** For $z < 0$ the output is $\tau z$, a small *negative* number (PyTorch: `negative_slope * z`). The Lecture 14 notebook writes $-\tau z$ for $z<0$, which would be positive; treat that as a typo.
> - **Sigmoid's derivative is not $e^{-z}$** or $\textrm{sigmoid}(z)$; it is $\textrm{sigmoid}(z)(1 - \textrm{sigmoid}(z))$, at most $0.25$.
> - **Activation after the last layer** before `CrossEntropyLoss` or `BCEWithLogitsLoss`: those losses expect logits.
> - **"ReLU is linear, so it doesn't help."** It is piecewise linear, not linear: $\textrm{ReLU}(a + b) \ne \textrm{ReLU}(a) + \textrm{ReLU}(b)$ in general (try $a = 1$, $b = -1$). That is enough to stop layers from collapsing.
> - **Forgetting the activation in a loop over layers** (see the [[5-deep-networks/multilayer-perceptrons#writing-an-mlp-in-pytorch|MLP page]]): the model silently becomes linear.
