> [!abstract] In one breath
> Semantic segmentation classifies **every pixel**: the target is a mask the size of the image, and the model (a fully convolutional network) outputs one score per pixel and class. With one class ("clothing or not") it outputs a $1\times H\times W$ map of logits, trained with pixel-wise binary cross-entropy; a logit above 0 means "clothing". It is evaluated with **intersection over union**, $\mathrm{IoU} = \lvert P\cap T\rvert / \lvert P\cup T\rvert$, because per-pixel accuracy is dominated by the easy background.

## What it is

![[l17-semantic-segmentation-example.png|Semantic segmentation: every pixel gets a class label]]

| task | input | output |
|---|---|---|
| image classification | $C\times H\times W$ | $K$ scores for the whole image |
| semantic segmentation | $C\times H\times W$ | $K\times H\times W$ scores (or $1\times H\times W$ for one class): a label per pixel |

"Semantic" means pixels get a *class*; two shirts touching are both just "clothing" (telling them apart would be *instance* segmentation, not covered).

## What you should know

- Output and target shapes: logits $N\times1\times H\times W$, mask $N\times1\times H\times W$ of 0s and 1s.
- Loss: [`F.binary_cross_entropy_with_logits`](https://docs.pytorch.org/docs/stable/generated/torch.nn.functional.binary_cross_entropy_with_logits.html) averages the BCE over all pixels.
- Prediction: `logits > 0`, the same as `sigmoid(logits) > 0.5`.
- $\mathrm{IoU} = \dfrac{\lvert P\cap T\rvert}{\lvert P\cup T\rvert}$: 1 for a perfect mask, 0 for no overlap. In code: `(pred * target).sum() / ((pred + target) > 0).sum()`.
- Why not accuracy: 84% of the validation pixels are background, so "no clothes anywhere" is already 84% accurate. A scene with IoU 0.52 still had 90.2% pixel accuracy.
- Geometric augmentation must move the image and its mask together ([[5-deep-networks/data-augmentation#augmenting-images-and-masks|augmenting masks]]).

## The data: Find the clothes

Lecture 16 pastes two FashionMNIST garments at random positions onto a $64\times64$ canvas with background noise; the mask marks every clothing pixel.

```python
def make_scenes(n, k=2):
    images, masks = torch.zeros(n, 1, 64, 64), torch.zeros(n, 1, 64, 64)
    for i in range(n):
        for _ in range(k):
            obj = X_train[torch.randint(N_TRAIN, (1,))].squeeze(0)   # 28 x 28
            r, c = torch.randint(0, 64 - 28, (2,)).tolist()
            m = (obj > 5 / 255).float()                              # object's own pixels
            images[i, 0, r:r+28, c:c+28] = images[i, 0, r:r+28, c:c+28] * (1 - m) + obj * m
            masks[i, 0, r:r+28, c:c+28] = masks[i, 0, r:r+28, c:c+28] * (1 - m) + m
    background = (images == 0).float()
    return images + background * torch.rand_like(images) / 3, masks   # noise in [0, 1/3)

scenes_train, masks_train = make_scenes(500)
scenes_val, masks_val = make_scenes(100)
```

(The lecture version also takes `distractors=True`, which adds MNIST digits with mask value 0: things that look like objects but are not clothing.) The background noise is at most $1/3$, so dark garments are hard to tell from it.

## Training

```python
model = EncoderDecoder(skip=True).to(device)          # the U-Net
optimizer = torch.optim.Adam(model.parameters(), lr=2e-3)
for epoch in range(12):
    model.train()
    for idx in torch.randperm(len(scenes_train)).split(32):
        optimizer.zero_grad()
        logits = model(scenes_train[idx].to(device))  # 32 x 1 x 64 x 64
        F.binary_cross_entropy_with_logits(logits, masks_train[idx].to(device)).backward()
        optimizer.step()
```

The model and its shapes are on [[5-deep-networks/fully-convolutional-networks#encoder-decoder-and-u-net|fully convolutional networks]]. Validation IoU: encoder-decoder 0.841, U-Net 0.868.

## Intersection over union

$$
\mathrm{IoU} = \frac{\lvert\,\text{predicted}\cap\text{target}\,\rvert}{\lvert\,\text{predicted}\cup\text{target}\,\rvert}
= \frac{\text{both}}{\text{both} + \text{false alarms} + \text{misses}}
$$

```python
def my_iou(pred, target):
    # pred, target: same shape, 0s and 1s
    intersection = (pred * target).sum()
    union = ((pred + target) > 0).sum()
    return (intersection / union).item()

a = torch.tensor([[1., 1., 0.], [0., 1., 0.]])
b = torch.tensor([[1., 0., 0.], [0., 1., 1.]])
print(my_iou(a, b), my_iou(a, a), my_iou(a, 1 - a))
```

```
0.5 1.0 0.0
```

For `a` and `b`: both are 1 at two pixels, $(0,0)$ and $(1,1)$; either is 1 at four, so $2/4 = 0.5$. `pred * target` is 1 only where both are 1 (logical AND); `(pred + target) > 0` is the logical OR.

> [!example] Accuracy vs IoU on one hard scene
> Lecture 16 shows the U-Net's prediction on its second-worst validation scene (the median IoU per scene is 0.90). Most of a dark garment is no brighter than the background noise, so the model misses it:
> ```
> iou() from the training cell, same image: 0.520
> per-pixel accuracy on the same image: 90.2%
> ```
> The lecture's figure counts the pixels: intersection 436, union 838, so $\mathrm{IoU} = 436/838 = 0.52$. The $838 - 436 = 402$ pixels in the union but not the intersection are exactly the wrong pixels, so accuracy is $(4096 - 402)/4096 = 90.2\%$ of the $64\times64$ image.
> Accuracy rewards the thousands of correctly empty background pixels; IoU only looks at the object.

> [!note] Pooled vs per-image IoU
> Lecture 16's `iou(logits, masks)` sums the intersection and the union over **all** pixels of the whole validation batch, then divides once: a pooled IoU over the dataset. Averaging the IoU of each image separately gives a different number (big objects count less). For several classes, the usual report is the IoU of each class and their mean (mIoU).

> [!trap] Common mistakes
> - Reporting pixel accuracy for segmentation: with mostly background it looks great even for an empty prediction.
> - Thresholding probabilities at 0 or logits at 0.5: logits $>0$ $\iff$ probabilities $>0.5$.
> - Both masks empty: IoU is $0/0$. Decide a convention (skip the image, or count it as 1) before averaging.
> - Using `nn.CrossEntropyLoss` with a single output channel: for one class use BCE with logits on $1\times H\times W$; for $K$ classes output $K\times H\times W$ logits and give `CrossEntropyLoss` an $N\times H\times W$ map of class indices.
> - Augmenting the image without the mask (or with different random parameters): the labels no longer line up.
