> [!abstract] In one breath
> `a[rows, cols]` picks parts of a tensor, one comma-separated entry per dimension, zero-indexed, with `start:stop:step` slices whose **stop is excluded**. Integers and slices are **basic indexing** and return a view; a **list or tensor of indices** gathers a copy; a **boolean mask** (a "truth array" such as `a > 30`) selects the matching elements into a **1-D copy**. Combine conditions with `&`, `|`, `~` and parenthesize every comparison.

## What it is

Rules from Lecture 2:

- Dimensions are **zero-indexed**: the first row is `a[0]`.
- Dimensions are **row-major**: in 2-D, `a[row, col]`.
- Separate dimensions with a comma; a missing trailing index means "all": `a[2]` is `a[2, :]`.
- Slices are `start:stop:step`, all optional, and **stop is exclusive**: `x[2:5]` is `x[2], x[3], x[4]`.
- Negative indices count from the end: `a[2, -1]` is the last element of row 2; `x[-1, ::3]` is every third element of the last row.

## What you should know

- An **integer** index removes that dimension; a **slice** keeps it. `a[2]`, `a[2, :]`, `a[:, 3]` are 1-D; `a[2:3, :]` has shape $(1, n)$.
- The number of elements a slice takes: $\lceil(\text{stop}-\text{start})/\text{step}\rceil$. `::2` on 8 rows is 4 rows; `1:8:3` is 1, 4, 7.
- Basic slicing returns a **view**; list/tensor indexing and masks return **copies** ([[1-foundations/storage-and-views|storage and views]]).
- `a[mask]` with a mask of `a`'s shape is **always 1-D**, elements in row-major order.
- Conditions: `a[(a > 0) & (a % 5 == 0)]`. Never `and`/`or`/`not`; always parentheses.
- `%` follows Python: the result has the sign of the divisor, so `-3 % 5 == 2`.
- Assigning through an index or mask (`a[a < 0] = 0`) modifies `a` in place.

## Basic indexing and slicing

```python
a = torch.rand(5, 4)
a[3, 2]          # one element: 0-d tensor
a[2, -1]         # last column of row 2

a = torch.rand([4, 3])
b = a[1:3, 1:2]  # rows 1-2, column 1: shape (2, 1)
```

## Advanced indexing: lists and tensors

A list (or integer tensor) in a dimension picks exactly those positions, in that order, and **copies**:

```python
a = torch.arange(100).view(10, 10)
b = a[[0, 1, 3, 4, 7], 1:5:3]   # listed rows, cols 1 and 4
```

```
tensor([[ 1,  4],
        [11, 14],
        [31, 34],
        [41, 44],
        [71, 74]])
```

> [!example] Fall 2024 Q2 — list indexing, view?, matrix product (15 pts)
> ```python
> x = torch.tensor([[1, -2, 3, -4], [-5, 6, 6, 5], [4, 3, 2, 1]])
> y = x[:, [0, 2, 3]]
> z = y.T @ x
> ```
> (a) $y = \begin{bmatrix}1&3&-4\\-5&6&5\\4&2&1\end{bmatrix}$, columns 0, 2 and 3 of every row.
> (b) Is `y` a view of `x`? **False**: indexing with a list allocates a new tensor.
> (c) $y^\top$ is $3\times3$ and $x$ is $3\times4$, so $z$ is $3\times4$:
> $$
> z = \begin{bmatrix}1&-5&4\\3&6&2\\-4&5&1\end{bmatrix}\begin{bmatrix}1&-2&3&-4\\-5&6&6&5\\4&3&2&1\end{bmatrix} = \begin{bmatrix}42&-20&-19&-25\\-19&36&49&20\\-25&41&20&42\end{bmatrix}
> $$

> [!warning] Two lists pair up
> Lists in **two** dimensions are matched element by element, not crossed: `a[[0, 1], [2, 3]]` is `tensor([a[0, 2], a[1, 3]])`, shape $(2,)$, not a $2\times2$ block. For a block, slice one dimension (`a[[0, 1], 2:4]`) or index twice (`a[[0, 1]][:, [2, 3]]`).

## Boolean masks (truth arrays)

A comparison produces a `bool` tensor of the same shape, a **truth array**; indexing with it keeps the elements where it is `True`:

```python
a = torch.randint(low=0, high=100, size=(10, 10))
b = a > 30          # (10, 10) of True/False
a[b]                # 1-D: every element > 30
c = (a % 6) == 0
a[c]                # multiples of 6, row-major order
```

The result is **1-D** because the selected elements need not form a rectangle. It is a copy.

### Combining conditions

| Goal | Code | Seen in |
|---|---|---|
| magnitude greater than ½ | `a[torch.abs(a) > 0.5]` | Fall 2024 Q1(b) |
| positive multiples of 5 | `a[(a > 0) & (a % 5 == 0)]` | Fall 2025 Q2(c) |
| negative multiples of 9 | `x[(x < 0) & (x % 9 == 0)]` | Lecture 2 |
| two more than a multiple of 5 | `x[x % 5 == 2]` | Lecture 2 |
| greater than the mean | `a[a > a.mean()]` | HW 1 Q3 |
| multiples of 4 in column 3 | `e = a[:, 3]; h = e[e % 4 == 0]` | Lecture 12 review |
| outside $[-1, 1]$ | `a[(a < -1) \| (a > 1)]` | |
| not zero | `a[~(a == 0)]`, same as `a[a != 0]` | |

> [!trap] Syntax that costs points
> - Use `&` (and), `|` (or), `~` (not) on tensors. `and`, `or`, `not` raise *"Boolean value of Tensor with more than one value is ambiguous"*.
> - **Parenthesize every comparison.** `&` binds tighter than `>` and `==`, so `a > 0 & a % 5 == 0` parses as `a > (0 & (a % 5)) == 0`, a chained comparison, and raises the same error.
> - `%` takes the divisor's sign: `-3 % 5 == 2` and `-78 % 5 == 2`, so `x[x % 5 == 2]` also returns $-3, -8, -78, \dots$ (they are two more than a multiple of 5 as well). For "positive" or "negative" add a sign condition.
> - `a.mean()` needs a float tensor; on an integer tensor call `a.float().mean()`.

> [!example] Lecture 2 exercise — slicing and truth arrays
> For `x = torch.randint(low=-99, high=100, size=(10, 10))`:
> ```python
> x[-1, ::3]                       # (a) every 3rd elem, last row
> x[(x % 5) == 2]                  # (b) two more than multiple of 5
> x[(x < 0) & ((x % 9) == 0)]      # (c) negative multiples of 9
> ```
> In the lecture's run, (b) returned `-78, -73, 77, 32, 37, -28, …`: negatives included, by the `%` rule above.

> [!example] Lecture 12 review — fill in the blanks
> `a` is a $(10, 10)$ tensor; `d = a[b, c]`, `e = a[f, g]`, `h = e[i]`.
> (a) `d` is the top-right quadrant: `b = 0:5`, `c = 5:`, i.e. `d = a[0:5, 5:]`.
> (b) `h` is every multiple of 4 in the third column (zeroth = index 0): `f = :`, `g = 3`, `i = e % 4 == 0`, i.e. `e = a[:, 3]; h = e[e % 4 == 0]`.

> [!example] HW 1 Q3
> (a) Columns 1 and 3: `b = a[:, [1, 3]]` (a copy). (b) Elements greater than the mean: `b = a[a > a.mean()]`. (c) `a[::n, ::n]` keeps every $n$-th row and every $n$-th column: a subsampled grid, and a view of `a`.

## Writing through an index or a mask

Reading `a[mask]` copies, but **assignment** writes into `a`:

```python
a[a < 0] = 0             # clamp negatives in place
a[:, [0, 2]] = -1        # list index on left: also in place
```

> [!example] Spring 2026 Q2(a) — broadcast, then a masked update
> ```python
> data = torch.zeros((3, 2))
> bias = torch.tensor([[10.], [20.], [30.]])   # (3, 1)
> result = data + bias                          # broadcasts to (3, 2)
> result[result > 15] -= 5
> ```
> `result` is $(3, 2)$ ([[1-foundations/broadcasting|broadcasting]]) with rows 10, 20, 30; the update subtracts 5 wherever the entry exceeds 15, giving $\begin{bmatrix}10&10\\15&15\\25&25\end{bmatrix}$.

## Choosing elementwise with torch.where

[`torch.where(cond, x, y)`](https://docs.pytorch.org/docs/stable/generated/torch.where.html) returns a tensor of the **same shape** that takes `x` where `cond` is true and `y` elsewhere: the shape-preserving alternative to a mask. HW 1 Q4 used it for the soft-shrink function $\operatorname{sign}(x)\max(\lvert x\rvert-\tau, 0)$:

```python
x_sign, x_abs = torch.sign(x), torch.abs(x)
result = x_sign * torch.where(x_abs - tau > 0, x_abs - tau, y)  # y: zeros
```

For $x = (1, 3, -1, -4, 5, -6)$ and $\tau = 2$ the result is $(0, 1, 0, -2, 3, -4)$. Called with only a condition, `torch.where(cond)` returns the **indices** where it holds (like [`torch.nonzero`](https://docs.pytorch.org/docs/stable/generated/torch.nonzero.html)).

> [!trap] Common mistakes
> - Off-by-one: the stop is excluded. Columns "1 through 7 every 3" is `1:8:3`, not `1:7:3` (which gives 1, 4 only).
> - Expecting `a[mask]` to keep `a`'s shape. It is 1-D; use `torch.where` to keep the shape.
> - Expecting `a[2]` to be $(1, n)$. An integer drops the dimension; `a[2:3]` keeps it.
> - Treating `a[:, [1, 3]]` as a view. Lists copy.
