> [!abstract] In one breath
> Any formula is a composition of simple operations (add, multiply, square, cos, exp, …). Drawing each intermediate result as a node and each "feeds into" relation as an arrow gives a **computational graph**, a directed acyclic graph. The **forward pass** evaluates the nodes from the inputs to the output (the **seed node**) and stores every value; each arrow carries a **local partial derivative** of the child with respect to the parent, which the [[2-calculus-and-optimization/backpropagation|backward pass]] multiplies and sums.

## What it is

Lecture 5 decomposes

$$
f(x,y)=x^2\cos(xy)+1
$$

into one operation per node:

$$
z_1=x,\quad z_2=y,\quad z_3=z_1^2,\quad z_4=z_1z_2,\quad z_5=\cos z_4,\quad z_6=z_3z_5,\quad z_7=z_6+1=f .
$$

Substituting back checks the decomposition: $z_7=z_3z_5+1=z_1^2\cos(z_1z_2)+1=x^2\cos(xy)+1$.

![[l05-computational-graph.png|Computational graph of f(x, y) = x² cos(xy) + 1]]

> [!definition] Vocabulary
> - **Computational graph**: a directed acyclic graph (DAG). Nodes hold values; an arrow $z_i\to z_j$ means $z_i$ is an input of the operation that produces $z_j$.
> - **Input nodes**: the variables ($z_1=x$, $z_2=y$). Parameters to be learned are input nodes too.
> - **Successors** of $z_i$: nodes its arrows point to. **Predecessors**: nodes pointing into it.
> - **Seed node**: a node with no successors — the output, usually the loss. Backpropagation starts there.
> - **Forward pass**: evaluate every node from inputs to seed, storing each value.
> - **Local partial** on arrow $z_i\to z_j$: $\partial z_j/\partial z_i$, holding $z_j$'s other inputs fixed.

## What you should know

- Decompose a formula into one simple operation per node, and draw (or read) the graph.
- Run the forward pass with numbers and give every node's value, also as a formula in the original variables.
- Write the local partial for every arrow, in node variables, from the table below.
- Spot **fan-out**: a node with several outgoing arrows (like $z_1$ above, used by $z_3$ and $z_4$). Its adjoint will be a sum.
- Read the exam convention: **the label on an arrow is the value of the node the arrow leaves**.
- The graph is built during the forward computation — PyTorch does the same thing whenever a tensor with `requires_grad=True` is used ([[2-calculus-and-optimization/autograd|autograd]]).

## The forward pass, with numbers

At $(x,y)=(2,\tfrac\pi2)$: $z_1=2$, $z_2=\tfrac\pi2$, $z_3=4$, $z_4=\pi$, $z_5=\cos\pi=-1$, $z_6=4\cdot(-1)=-4$, $z_7=-3$.

![[l05-forward-pass.png|Forward pass at (x, y) = (2, π/2): every node stores its value]]

The stored values are what make the backward pass cheap: every local partial is a simple expression in these numbers.

## Local partials

| node | $\partial z/\partial u$ | $\partial z/\partial v$ |
|---|---|---|
| $z=u+v$ | $1$ | $1$ |
| $z=u-v$ | $1$ | $-1$ |
| $z=uv$ | $v$ | $u$ |
| $z=u/v$ | $1/v$ | $-u/v^2$ |
| $z=cu$, $z=u+c$ ($c$ constant) | $c$, $1$ | |
| $z=u^n$ | $nu^{n-1}$ | |
| $z=e^u$ | $e^u=z$ | |
| $z=\ln u$ | $1/u$ | |
| $z=\sin u$, $z=\cos u$ | $\cos u$, $-\sin u$ | |
| $z=\sigma(u)$ | $z(1-z)$ | |

For the graph above the local partials are $\partial z_7/\partial z_6=1$, $\partial z_6/\partial z_3=z_5$, $\partial z_6/\partial z_5=z_3$, $\partial z_5/\partial z_4=-\sin z_4$, $\partial z_4/\partial z_1=z_2$, $\partial z_4/\partial z_2=z_1$, $\partial z_3/\partial z_1=2z_1$:

## Reading exam figures

> [!tip] The arrow-label convention
> On the exams and in HW 2, the label written on an arrow leaving a node is **that node's value**, in terms of its inputs. In Fall 2025 the arrow $a_2\to a_5$ is labeled $a_1^2$, so $a_2=a_1^2$; the arrow out of $a_6$ is labeled $a_3+a_4+a_5$, so $a_6=a_3+a_4+a_5$. Every arrow leaving the same node carries the same label. (The Lecture 5 figures follow the same rule: the arrow out of $z_6$ is labeled $z_3z_5$.)

> [!trap] Common mistakes
> - Giving a node's value only in node variables when the question says "in terms of $x$" (or the reverse).
> - Mis-reading arrow labels as operations applied *on* the arrow; they name the value of the source node.
> - Writing a **full** derivative ($\partial f/\partial z_i$) where a **local** partial ($\partial z_j/\partial z_i$) is asked.
