*Lectures 3–4 · [[2-calculus-and-optimization/index|Calculus and optimization]] · builds on [[2-calculus-and-optimization/gradients-and-partial-derivatives|gradients]] · leads to [[2-calculus-and-optimization/gradient-descent|gradient descent]]*

> [!abstract] In one breath
> Training a model means solving $\min_\theta f(\theta)$ for an **objective function** $f$ that scores how badly the model fits. Minima and maxima of a differentiable $f$ are **critical points**, where $\nabla f=0$; the second derivative says which kind. For **convex** functions every critical point is a global minimum. Solving $\nabla f=0$ in closed form works for linear regression but is usually intractable, and models have millions of parameters — so we iterate instead.

## What it is

> [!definition] Definition — optimization problem
> $$
> \min_{x}\ f(x)
> $$
> "Find the $x$ that makes the **objective function** $f$ as small as possible." Optimizing the original ("primary") function directly is **primal optimization**; constrained problems also come with a **dual problem**, which this course does not use. The problem is **unconstrained** if every $x$ is allowed and **constrained** otherwise, e.g.
> $$
> \max_{x,y}\ (1-x)^2+\frac1y\quad\text{subject to}\quad x+y=1,\ x\ge0,\ y>0 .
> $$

Maximizing $f$ is the same as minimizing $-f$, so everything below is phrased as minimization.

The first ML example ([[3-linear-models/linear-regression|linear regression]]): given data $\{(x_i,y_i)\}_{i=1}^N$, choose a slope $m$ and intercept $b$ to

$$
\min_{m,b}\ \frac1N\sum_{i=1}^N(mx_i+b-y_i)^2 .
$$

The errors are squared so that positive and negative errors count the same and cannot cancel (and so that the objective is smooth).

## What you should know

- The vocabulary: objective function (also loss or cost), optimization variables, constrained vs unconstrained, minimizer $x^*$ vs minimum value $f(x^*)$.
- **Critical (stationary) points** are where $f'(x)=0$ or $\nabla f(x)=0$.
- **Second-derivative test** (one variable): $f''>0$ local minimum, $f''<0$ local maximum, $f''=0$ inconclusive ($x^3$ at 0). In several variables the Hessian plays this role; the course does not test it.
- **Convexity**: $f(\lambda x_1+(1-\lambda)x_2)\le\lambda f(x_1)+(1-\lambda)f(x_2)$ for all $x_1,x_2$ and $0\le\lambda\le1$; for twice-differentiable $f$ of one variable, equivalently $f''(x)\ge0$ everywhere.
- For a convex function every critical point is a **global** minimum, so gradient descent (with a good step size) finds it. Non-convex functions can have many local minima.
- Two reasons not to rely on solving $\nabla f=0$: the equation may be intractable, and the parameter space is huge.

**Worked.** $f(x)=(x-3)^2$: $f'(x)=2(x-3)=0$ gives $x=3$, and $f''=2>0$, so $x^*=3$ is a minimum with value $0$.

**Worked, two variables.** $f(x,y)=x^2+2y^2-2x$: $\nabla f=(2x-2,\ 4y)=0$ gives $(x^*,y^*)=(1,0)$ and $f(1,0)=-1$. The function is a sum of convex parabolas, so this is the global minimum.

**Worked, minimum value vs minimizer (Fall 2025 Q3(b)).** $f(x)=(x^\top x-3)^2$ for $x\in\mathbb{R}^3$ is never negative, and it is $0$ exactly when $\Vert x\Vert_2^2=3$. So the minimum value is $0$, attained at infinitely many minimizers — $(1,1,1)$, $(\sqrt3,0,0)$, any point on the sphere of radius $\sqrt3$. (Also $x=0$ is a critical point, since $\nabla f=4(x^\top x-3)x=0$ there, but $f(0)=9$: it is a local *maximum*.)

Examples: $x^2$, $(x-1)^2$, $e^x$, $|x|$, $\Vert y-Ax\Vert_2^2$ and every MSE objective of a model that is linear in its parameters are convex. $x^3$, $\cos x$ and the Lecture 4 function $x^2+2\cos(\pi x)+x+2$ (second derivative $2-2\pi^2\cos(\pi x)$, negative near even integers) are not. Strict and strong convexity are refinements (left to ECE 490).

> [!key] Why convexity matters
> If $f$ is convex and differentiable, $\nabla f(x^*)=0$ implies $x^*$ is a **global** minimizer. That is why [[3-linear-models/linear-regression|linear regression]] (convex) can be solved by setting the gradient to zero, and why [[2-calculus-and-optimization/gradient-descent|gradient descent]] with a suitable step size finds its global minimum; on non-convex functions such as neural-network losses, gradient descent only promises a point that is locally good.

## Why not always set the gradient to zero?

**1. The equation can be intractable.** Lecture 3's example

$$
f(x)=\tfrac13(x-1)^6-(x-2)^5+5x^4,\qquad f'(x)=2(x-1)^5-5(x-2)^4+20x^3 ,
$$

has no usable closed-form root. (Numerically, $f'$ changes sign once on $[0,2]$, at $x^*\approx0.8018$, where $f\approx4.536$; gradient descent finds it on the [[2-calculus-and-optimization/gradient-descent#a-non-quadratic-example|gradient-descent page]].)

**2. There are too many parameters.** Models have thousands to billions of parameters, so solving (or even visualizing) $\nabla f=0$ in that many unknowns is infeasible.

The fix is an iterative method that only needs to **evaluate** the gradient: [[2-calculus-and-optimization/gradient-descent|gradient descent]], with gradients supplied by [[2-calculus-and-optimization/backpropagation|backpropagation]].

> [!trap] Common mistakes
> - Confusing the minimizer $x^*$ with the minimum value $f(x^*)$ — exams ask for one or the other.
> - Concluding "minimum" from $f'(x)=0$ alone: $x^3$ has a critical point at 0 that is neither.
> - Thinking convexity means "has one critical point": a convex function can have a whole set of minimizers (a flat bottom), but they all share the global minimum value.
