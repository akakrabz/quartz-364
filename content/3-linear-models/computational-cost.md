*Lecture 8 · [[3-linear-models/index|Linear models]] · builds on [[3-linear-models/multiple-linear-regression|multiple linear regression]] and [[2-calculus-and-optimization/gradient-descent|gradient descent]]*

> [!abstract] In one breath
> For $X\in\mathbb{R}^{N\times d}$, the closed form $w^* = (X^\top X)^{-1}X^\top y$ costs $\mathcal{O}(Nd^2 + d^3)$: forming $X^\top X$ is $Nd^2$ and inverting it is $d^3$. One gradient-descent step costs $\mathcal{O}(Nd)$, so $k$ steps cost $\mathcal{O}(Ndk)$. Both are linear in $N$; the difference is in $d$. The closed form gets expensive when there are **many features**, not when there are many data points.

## What you should know

- Cost of a matrix product $(n\times p)(p\times m)$: $\mathcal{O}(npm)$ multiply-adds. Cost of inverting an $n\times n$ matrix: $\mathcal{O}(n^3)$.
- Closed form, step by step: $X^\top X$ is $\mathcal{O}(Nd^2)$, the inverse $\mathcal{O}(d^3)$, $X^\top y$ is $\mathcal{O}(Nd)$, the final product $\mathcal{O}(d^2)$. Total $\mathcal{O}(Nd^2 + d^3)$.
- Gradient step $\frac2NX^\top(Xw-y)$: $Xw$ is $\mathcal{O}(Nd)$, the subtraction $\mathcal{O}(N)$, $X^\top(\cdot)$ is $\mathcal{O}(Nd)$. Total $\mathcal{O}(Nd)$ per step, $\mathcal{O}(Ndk)$ for $k$ steps.
- When $N\gg d$, both grow linearly in $N$; increasing $N$ alone does **not** make gradient descent the cheaper method.
- When $d$ is large (but still $d\le N$), the $d^2$ and $d^3$ terms make the closed form much more expensive, and gradient descent wins.
- Gradient descent is approximate; the closed form is exact (when $X^\top X$ is invertible).

## Counting the operations

**Closed form.** With $X\in\mathbb{R}^{N\times d}$ and $y\in\mathbb{R}^N$:

| step | result shape | cost |
|---|---|---|
| $X^\top X$ | $d\times d$ | $\mathcal{O}(Nd^2)$ |
| $(X^\top X)^{-1}$ | $d\times d$ | $\mathcal{O}(d^3)$ |
| $X^\top y$ | $d$ | $\mathcal{O}(Nd)$ |
| $(X^\top X)^{-1}(X^\top y)$ | $d$ | $\mathcal{O}(d^2)$ |
| **total** | | $Nd^2 + d^3 + Nd + d^2 = \mathcal{O}(Nd^2 + d^3)$ |

**Gradient descent**, per iteration, with $\nabla_wJ = \frac2NX^\top(Xw - y)$:

| step | result shape | cost |
|---|---|---|
| $Xw$ | $N$ | $\mathcal{O}(Nd)$ |
| $Xw - y$ | $N$ | $\mathcal{O}(N)$ |
| $\frac2NX^\top(Xw-y)$ | $d$ | $\mathcal{O}(Nd)$ |
| **per step** | | $2Nd + N = \mathcal{O}(Nd)$ |
| **$k$ steps** | | $\mathcal{O}(Ndk)$ |

## Which is cheaper?

With the lecture's exact counts, the ratio of the two costs is
$$
\frac{Nd^2 + Nd + d^3 + d^2}{k\,(2Nd + N)} \approx \frac{Nd^2 + d^3}{2kNd} = \frac{d}{2k}\left(1 + \frac{d}{N}\right).
$$
With $d\le N$ the bracket is between 1 and 2, so the closed form costs about $d/(2k)$ times as much as $k$ steps of gradient descent: **closed form when $d$ is small compared with the number of iterations you would need, gradient descent when $d$ is large.** $N$ cancels to leading order. Check against the lecture's heat maps (natural log): $N = 10^6$, $d = 100$, $k = 1$ gives a ratio of about 50 (the map shows $3.92\approx\ln 50$), and $d = k = 1000$ gives about $\frac12$ (the map shows $-0.69 = \ln\frac12$).

```python
# Lecture 8: compare the two cost formulas
matrix_complexity = N*d**2 + N*d + d**3 + d**2
gd_complexity = k*(2*N*d + N)
ratio = matrix_complexity / gd_complexity   # > 1: GD cheaper
```

The lecture's heat maps of $\log(\text{matrix}/\text{GD})$ over grids of $N$ and $d$ (for $k = 1, 10, 100, 1000$) show the same thing: moving along the $N$ axis barely changes the ratio, moving along the $d$ axis changes it a lot, and more iterations shift the balance back toward the closed form.

> [!intuition] Why deep learning uses gradient descent
> A linear model on raw $28\times 28$ images already has $d = 784$; modern networks have millions of parameters, and most models have no closed form at all ([[3-linear-models/logistic-regression|logistic regression]] is the first one in this course). Gradient descent needs only the gradient, which [[2-calculus-and-optimization/backpropagation|backpropagation]] supplies at about the cost of one forward pass.

> [!trap] Common mistakes
> - **"More data favors gradient descent."** Both methods are linear in $N$. It is $d$ that matters.
> - **Forgetting the iterations.** The fair comparison is one closed-form solve against $k$ gradient steps, not against one step.
> - **Counting the inverse as $N^3$.** The matrix being inverted is $X^\top X$, which is $d\times d$.

> [!exam] On the exams
> Fall 2025 true/false (b): *"As $N$ increases and $d$ remains fixed, gradient descent will become more computationally efficient than the closed-form solution."* **False**: both costs grow linearly in $N$. See [[6-midterm-1/fall-2025|Fall 2025]] and the [[6-midterm-1/true-false|true/false bank]].

## PyTorch docs

- [`torch.linalg.solve`](https://docs.pytorch.org/docs/stable/generated/torch.linalg.solve.html) — solves $Aw = b$ by factorization, which is cheaper and more stable than forming the inverse.
- [`torch.linalg.inv`](https://docs.pytorch.org/docs/stable/generated/torch.linalg.inv.html) — the explicit $\mathcal{O}(d^3)$ inverse.

- [`torch.matmul`](https://docs.pytorch.org/docs/stable/generated/torch.matmul.html) — the products being counted.
- [`torch.optim.SGD`](https://docs.pytorch.org/docs/stable/generated/torch.optim.SGD.html) — the iterative alternative, used for every model from Lecture 10 on.
