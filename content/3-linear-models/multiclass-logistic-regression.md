*Lectures 9 and 11 · [[3-linear-models/index|Linear models]] · builds on [[3-linear-models/logistic-regression|logistic regression]] and [[3-linear-models/binary-cross-entropy|binary cross-entropy]]*

> [!abstract] In one breath
> With $K$ classes, give each class its own weight vector and bias and compute a score (a **logit**) for each: $z = Wx + b\in\mathbb{R}^K$, where row $k$ of $W$ is $w_k^\top$. Predict the class with the largest score. To get probabilities, apply **softmax**, $\Pr\{y=k\mid x\} = e^{z_k}/\sum_je^{z_j}$, which keeps the order of the scores. Train by minimizing the **cross-entropy** $-\log\Pr\{y = y_i\mid x_i\}$, whose gradient with respect to the logits is $\mathrm{softmax}(z) - \mathrm{onehot}(y)$. In PyTorch this is an `nn.Linear(d, K)` followed by `nn.CrossEntropyLoss`, which takes **logits** and integer labels.

## What it is

Binary logistic regression gives one probability and its complement. With $K > 2$ classes (digits 0–9, ten kinds of clothing) there are two ways to build a classifier out of binary ones.

| scheme | classifiers | how it predicts |
|---|---|---|
| **one vs. one** | one per pair of classes: $\binom K2 = \frac{K(K-1)}2$ | each class takes part in $K-1$ duels; the class that wins most often is predicted |
| **one vs. all** (one vs. rest) | $K$, one per class | classifier $k$ treats class $k$ as positive and all others as negative; the class with the highest score is predicted |

Multi-class logistic regression is one vs. all: each class $k$ has a weight vector $w_k\in\mathbb{R}^d$ and bias $b_k$, and
$$
z_k = w_k^\top x + b_k .
$$
Stacking the $w_k^\top$ as the rows of a $K\times d$ matrix computes every score at once:
$$
z = Wx + b = \begin{bmatrix} w_1^\top\\ w_2^\top\\ \vdots\\ w_K^\top\end{bmatrix} x + \begin{bmatrix}b_1\\ b_2\\ \vdots\\ b_K\end{bmatrix} = \begin{bmatrix}z_1\\ z_2\\ \vdots\\ z_K\end{bmatrix}.
$$
The prediction is $\hat y = \arg\max_k z_k$.

## What you should know

- One vs. one needs $K(K-1)/2$ classifiers, one vs. all needs $K$. Multi-class logistic regression is one vs. all.
- Shapes: $W$ is $K\times d$, $b$ and $z$ have length $K$; for a batch, the logits are $N\times K$.
- Softmax: $\mathrm{Softmax}(z)_k = \dfrac{e^{z_k}}{\sum_{j=1}^{K}e^{z_j}}$. Outputs are positive, sum to 1, and keep the order of the logits, so $\arg\max$ of the probabilities equals $\arg\max$ of the logits.
- Softmax is unchanged by adding the same constant to every logit.
- Cross-entropy: $\ell_{\text{ce}}(f(x), y) = -\sum_k\mathbf{1}\{y=k\}\log f_k(x) = -\log f_y(x) = -z_y + \log\sum_je^{z_j}$.
- The training problem is $\min_{W,b}\sum_i\ell_{\text{ce}}$ (a **minimum** of a positive loss).
- Gradient: $\dfrac{\partial\ell_{\text{ce}}}{\partial z} = \mathrm{softmax}(z) - \mathrm{onehot}(y)$.
- `nn.CrossEntropyLoss` takes raw logits (it applies log-softmax itself) and `long` class indices $0,\dots,K-1$.
- Each region where one class wins is bounded by straight lines; row $w_k$ of $W$ points toward class $k$.

## Softmax

$$
\mathrm{Softmax}(z)_k = \Pr\{y = k\mid x\} = \frac{e^{z_k}}{\sum_{j=1}^{K}e^{z_j}} .
$$
Exponentiating makes every entry positive; dividing by the sum makes them add to 1. Because $e^{t}$ is increasing, larger logits give larger probabilities, so softmax never changes which class is on top.

> [!key] Softmax facts
> - **Shift invariance:** $\mathrm{Softmax}(z + c\mathbf 1) = \mathrm{Softmax}(z)$, because $e^{z_k+c}/\sum_je^{z_j+c} = e^{z_k}/\sum_je^{z_j}$. Implementations subtract $\max_j z_j$ first so the exponentials cannot overflow.
> - **Two classes reduce to the sigmoid:** $\mathrm{Softmax}(z)_1 = \dfrac{e^{z_1}}{e^{z_1}+e^{z_2}} = \dfrac1{1+e^{-(z_1-z_2)}} = \sigma(z_1 - z_2)$. Binary logistic regression is the $K = 2$ case with $w = w_1 - w_2$.
> - **Ties stay ties:** equal logits give equal probabilities.

## Cross-entropy loss

Let $f_k(x) = \mathrm{Softmax}(z)_k$. The cross-entropy picks out the log-probability of the correct class:
$$
\ell_{\text{ce}}(f(x), y) = -\sum_{k=1}^{K}\mathbf{1}\{y = k\}\log f_k(x) = -\log f_y(x) = -z_y + \log\sum_{j=1}^{K}e^{z_j},
$$
where $\mathbf{1}\{y=k\}$ is 1 if $y = k$ and 0 otherwise. Training minimizes the total:
$$
\min_{W,\,b}\ \sum_{i=1}^{N}\ell_{\text{ce}}\big(f_{W,b}(x_i),\ y_i\big).
$$
(Lecture 9 and the Lecture 12 review write this with an extra minus sign, $\min -\sum\ell_{\text{ce}}$; $\ell_{\text{ce}}$ already contains the minus, so the correct problem minimizes $+\sum\ell_{\text{ce}}$.) With $K = 2$ and 0/1 labels this is exactly [[3-linear-models/binary-cross-entropy|binary cross-entropy]].

From the last form, $\dfrac{\partial\ell_{\text{ce}}}{\partial z_k} = -\mathbf 1\{y=k\} + \dfrac{e^{z_k}}{\sum_je^{z_j}}$, i.e.
$$
\nabla_z\,\ell_{\text{ce}} = \mathrm{Softmax}(z) - \mathrm{onehot}(y),
$$
the multi-class version of BCE's $\sigma(z) - y$: push the correct logit up by $1 - f_y$ and every other logit down by its probability.

> [!example] Softmax and cross-entropy by hand
> Logits $z = (2, 0, -1)$. Then $e^{z} = (7.389,\ 1,\ 0.368)$ with sum $8.757$, so $\mathrm{Softmax}(z)\approx(0.844,\ 0.114,\ 0.042)$. If the true class is the second, $\ell_{\text{ce}} = -\ln 0.114\approx 2.17$; equivalently $-z_2 + \ln 8.757 = 0 + 2.17$. The gradient with respect to $z$ is $(0.844,\ 0.114 - 1,\ 0.042) = (0.844,\ -0.886,\ 0.042)$.

## Geometry: regions and weight vectors

Class $k$ wins where $z_k$ is the largest score. The boundary between classes $j$ and $k$ is where $z_j = z_k$, i.e. $(w_j - w_k)^\top x + (b_j - b_k) = 0$: a straight line. So the input space is cut into $K$ convex regions with straight edges, and each $w_k$ points roughly toward its own class's cluster.

> [!example] Fall 2025 Q6(b): which $W$ classifies the three marked points? (6 pts)
> From the plot: star $\approx(3,1)$ is class 1, square $\approx(-3,2)$ is class 2, triangle $\approx(-2,-3)$ is class 3. Multiply each point by $W$ (no bias) and take the largest entry.
>
> | $W$ (rows $w_1, w_2, w_3$) | star $(3,1)$ | square $(-3,2)$ | triangle $(-2,-3)$ |

> | $W_1 = [[2,-1],[-1,2],[-2,-1]]$ | $(5,-1,-7)\to 1$ ✓ | $(-8,7,4)\to 2$ ✓ | $(-1,-4,7)\to 3$ ✓ |
> | $W_2 = [[-1,2],[-2,-1],[2,-1]]$ | $(-1,-7,5)\to 3$ ✗ | $(7,4,-8)\to 1$ ✗ | $(-4,7,-1)\to 2$ ✗ |
> | $W_3 = [[2,1],[-2,1],[2,-1]]$ | $(7,-5,5)\to 1$ ✓ | $(-4,8,-8)\to 2$ ✓ | $(-7,1,-1)\to 2$ ✗ |
> | $W_4 = [[-2,1],[1,-2],[2,1]]$ | $(-5,1,7)\to 3$ ✗ | $(8,-7,-4)\to 1$ ✗ | $(1,4,-7)\to 2$ ✗ |
>
> **Answer: $W_1$.** Shortcut: each row $w_k$ should point toward its own class's points; in $W_1$, $w_1 = (2,-1)$ points right (star), $w_2 = (-1,2)$ up-left (square), $w_3 = (-2,-1)$ down-left (triangle).

> [!example] HW3 Q5: four classes, one vs. all, softmax
> $W = [[1, 3], [2, -1], [-3, 2], [-2, -1]]$, no bias.
> - $x_1 = (1,-1)$: $z = (-2, 3, -5, -1)\to$ class 2.
> - $x_2 = (-1,4)$: $z = (11, -6, 11, -2)\to$ a **tie** between classes 1 and 3 (softmax gives each $\approx 0.5$).
> - $x_3 = (0,5)$: $z = (15, -5, 10, -5)\to$ class 1.
> - (b) $x = (1,1)$: $z = (4, 1, -1, -3)$, $\mathrm{Softmax}(z)\approx(0.946,\ 0.047,\ 0.006,\ 0.001)$.

## In PyTorch

Lecture 9 writes the parameters out by hand and lets autograd find the gradients:

```python
# Lecture 9: 4 classes, 2-D inputs
W = torch.randn((4, 2), requires_grad=True)
b = torch.randn(4, requires_grad=True)
loss_fn = torch.nn.CrossEntropyLoss()
for n in range(500):
    logits = (W @ X.T).T + b        # (4N, 4) logits
    loss = loss_fn(logits, y)       # y: long, values 0..3
    loss.backward()
    with torch.no_grad():
        W -= 1e-2 * W.grad
        b -= 1e-2 * b.grad
    W.grad = None
    b.grad = None
```

Lecture 11 packages the same model as a module. [`nn.Linear(d, K)`](https://docs.pytorch.org/docs/stable/generated/torch.nn.Linear.html) holds $W$ (as `weight`, shape `(K, d)`) and $b$ (as `bias`, shape `(K,)`) and computes $xW^\top + b$ for a batch:

```python
class MulticlassLogisticRegression(nn.Module):
    def __init__(self, d, K):
        super().__init__()
        self.weight_matrix = nn.Linear(d, K, bias=True)

    def forward(self, x):
        return self.weight_matrix(x)    # logits, no softmax

def multiclass_model_accuracy(model, input_data, labels):
    predicted_classes = torch.argmax(model(input_data), dim=1)
    return torch.sum(torch.eq(predicted_classes, labels))
```

The full Lecture 11 pipeline trains it on Fashion-MNIST ($d = 28^2 = 784$, $K = 10$) with `nn.CrossEntropyLoss()`, `torch.optim.SGD(lr=1e-3, momentum=0.99, weight_decay=1e-4)`, batch size 64 and 100 epochs, logging training and validation accuracy each epoch. The pieces are explained in [[4-pytorch-training/nn-module|nn.Module]], [[4-pytorch-training/datasets-and-dataloaders|datasets and dataloaders]], [[4-pytorch-training/optimizers|optimizers]] and [[4-pytorch-training/training-loop|the training loop]].

> [!trap] Common mistakes
> - **Applying softmax before `nn.CrossEntropyLoss`.** It takes logits and applies log-softmax internally; softmax-ing first computes the wrong loss and weakens the gradients.
> - **Float labels of shape `(N,)`.** The course uses class-index targets: a `long` tensor of shape `(N,)` with values $0,\dots,K-1$ (hence `.long()` in the lecture code); float labels of that shape raise an error. (A float `(N, K)` target is read as class probabilities, a different mode the course does not use.)
> - **Logits shape.** `nn.CrossEntropyLoss` wants `(N, K)`; `argmax` over `dim=1` gives the predicted classes.
> - **Counting classifiers.** One vs. one is $K(K-1)/2$, not $K$. With $K = 10$ that is 45.
> - **Thinking softmax can change the prediction.** It preserves order; the argmax is the same.
> - **The sign of the objective.** Minimize $\sum_i\ell_{\text{ce}}$, not $-\sum_i\ell_{\text{ce}}$ (a typo in the lecture notes).

> [!exam] On the exams
> Fall 2025 Q6(b) (above) and HW3 Q5 are the templates: multiply by $W$, take the argmax, maybe compute a softmax. True/false favorites: one vs. one trains $K(K-1)/2$ classifiers; softmax does not change the top class; `nn.CrossEntropyLoss` expects logits.
