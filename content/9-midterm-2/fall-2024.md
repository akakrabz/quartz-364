## Problem 1 — True or false (30 pts)

> [!question] Problem 1
> Select True or False for each statement.
>
> **(a)** **[skipped]** Multi-class logistic regression models perform "one-vs-one" classification to generate the final class prediction.
>
> **(b)** A given multi-layer perceptron model requires inputs of a specific size, i.e. the size of the data cannot vary in the dataset during training or testing.
>
> **(c)** Pooling functions in convolutional neural networks must be non-linear functions.
>
> **(d)** Recurrent neural networks are not an example of feed-forward deep net models.
>
> **(e)** Long short-term memory networks achieve long-term and short-term time-dependencies by applying short and long skip connections between nearby and far away model layers, respectively.
>
> **(f)** Dropout is a technique for preventing overfitting in deep net models.
>
> **(g)** Batch norm is applied to normalize the color channels of input images to convolutional neural networks.
>
> **(h)** A training epoch is one full pass of model updates through the training dataset.
>
> **(i)** **[skipped]** Suppose we have a collection of $N$ 3-dimensional data points. The vectors $v_1 = \begin{bmatrix}1/2&\sqrt3/2&0\end{bmatrix}^\top$, $v_2 = \begin{bmatrix}0&1/2&\sqrt3/2\end{bmatrix}^\top$, $v_3 = \begin{bmatrix}\sqrt3/2&0&1/2\end{bmatrix}^\top$ represent a possible set of principal component vectors for the data.
>
> **(j)** **[skipped]** K-Means clustering can represent clusters as ellipsoids (ellipses in higher dimensions) while Gaussian Mixture Models can only represent spherical clusters.

> [!solution]- Solution
> **(a) False.** **[skipped]** The model produces one score per class and predicts the largest (softmax); it trains no pairwise classifiers. → [[3-linear-models/multiclass-logistic-regression|multi-class logistic regression]]
>
> **(b) True.** The first layer is `nn.Linear(in_features, …)`, a weight matrix with a fixed number of columns, so every input must have exactly `in_features` entries. (A CNN with global pooling, an RNN or a Transformer can take inputs of varying size.) → [[5-deep-networks/multilayer-perceptrons|MLPs]]
>
> **(c) False.** Average pooling is linear: it is a convolution with a constant kernel. Max pooling is non-linear. Pooling is there to shrink the feature map and summarize a neighbourhood, not to supply the non-linearity. → [[5-deep-networks/pooling|pooling]]
>
> **(d) True.** In a feed-forward network data flows once from input to output through a chain of layers (MLP, CNN). An RNN feeds its hidden state back into the same layer at the next time step. → [[5-deep-networks/recurrent-neural-networks|RNNs]]
>
> **(e) False.** An LSTM carries long-term information in a **cell state** $c_t = f_t\odot c_{t-1} + i_t\odot g_t$ controlled by **gates** (forget, input, output), all inside one recurrent layer across time steps. Skip connections between layers are the idea of ResNets. → [[5-deep-networks/lstm-and-gru|LSTM and GRU]]
>
> **(f) True.** Randomly zeroing activations during training keeps the network from relying on a few co-adapted units. → [[5-deep-networks/dropout|dropout]]
>
> **(g) False.** Batch norm normalizes **feature maps inside the network**: each channel's activations over the batch (and all pixels), followed by a learned scale and shift. Normalizing the colour channels of the input image is preprocessing (`transforms.Normalize`). → [[5-deep-networks/batch-normalization|batch normalization]]
>
> **(h) True.** One epoch = every training example used once = $\lceil N/\text{batch size}\rceil$ optimizer steps. → [[4-pytorch-training/training-loop|training loop]]
>
> **(i) False.** **[skipped]** Principal components are orthogonal to each other, and $v_1^\top v_2 = \sqrt3/4 \ne 0$.
>
> **(j) False.** **[skipped]** It is the other way round: K-Means clusters are round, and a Gaussian mixture can fit ellipsoids.

## Problem 2 — Datasets, DataLoaders and SGD (20 pts)

> [!question] Problem 2
> The following parts are unrelated.
>
> **(a)** State the three required methods for implementing a PyTorch `Dataset` class and provide a brief explanation of what each method is used for.
>
> **(b)** Suppose we would like to create separate PyTorch DataLoaders for the training and validation set of a dataset named `my_dataset`. The full dataset has 72 data points and we would like each dataloader to produce four batches on each complete pass through each dataloader. Complete the function below to implement the two dataloaders. Note: you may assume that `train_indices` and `validation_indices` are equal length.
> ```python
> from torch.utils.data import DataLoader, SubsetRandomSampler
> def split_dataset(my_dataset, training_indices, validation_indices):
>     # complete this function in available space below
>     return train_loader, validation_loader
> ```
> **(c)** For each of the following options, state whether the parameter is **required**, **optional**, or **not used** in order to initialize a `torch.optim.SGD` optimizer.
> i. Number of training epochs  ii. Momentum  iii. Learning rate  iv. Trainable model parameters  v. Weight decay  vi. Loss function

> [!solution]- Solution
> **(a)**
> 1. `__init__`: the constructor; loads or creates the data and stores any attributes.
> 2. `__len__`: makes `len(dataset)` work; returns the number of examples.
> 3. `__getitem__`: makes `dataset[idx]` work; returns the example (input and label) at integer index `idx`.
>
> **(b)** The two index lists have equal length, so each split has $72/2 = 36$ points. Four batches per pass means a batch size of $36/4 = 9$.
> ```python
> def split_dataset(my_dataset, training_indices, validation_indices):
>     train_sampler = SubsetRandomSampler(training_indices)
>     validation_sampler = SubsetRandomSampler(validation_indices)
>     train_loader = DataLoader(my_dataset, batch_size=9, sampler=train_sampler)
>     validation_loader = DataLoader(my_dataset, batch_size=9, sampler=validation_sampler)
>     return train_loader, validation_loader
> ```
> The key says syntax is not graded strictly; the points are the **batch size of 9**, the **use of a sampler** for each split, and **calling `DataLoader`** on the same dataset. (The key writes `train_indices` inside the function although the argument is named `training_indices`; see [[9-midterm-2/errata|errata]].)
>
> **(c)** `torch.optim.SGD(params, lr, momentum=0, weight_decay=0, …)`:
>
> | | parameter | key | why |
> |---|---|---|---|
> | i | number of training epochs | **Not used** | epochs belong to your training loop |
> | ii | momentum | **Optional** | default 0 |
> | iii | learning rate | **Required** | see the note below |
> | iv | trainable model parameters | **Required** | `model.parameters()`, the first argument |
> | v | weight decay | **Optional** | default 0 |
> | vi | loss function | **Not used** | the optimizer only reads `.grad`; the loss is computed separately |
>
> **Note on (iii).** The official key says *Required*, which was literally true of `torch.optim.SGD` when the course was written. Current PyTorch gives `lr` a default of `0.001`, and the formula sheet attached to the [[9-midterm-2/fall-2025#the-formula-sheet-that-came-with-the-exam|Fall 2025 exam]] prints `torch.optim.SGD(params, lr=0.001, momentum=0, weight_decay=0)`. (Confirmed with PyTorch 2.15: `torch.optim.SGD(model.parameters())` runs, with `lr = 0.001`.) If this is asked again, answer from the signature you are given, and say that in practice you always choose the learning rate yourself.

## Problem 3 — A custom block (20 pts)

> [!question] Problem 3
> Consider the following block to be used in a deep neural network. The block takes input $x\in\mathbb R^N$ and produces an output vector $z\in\mathbb R^D$. Let $z = f(x)$ denote the final output, $\sigma$ an arbitrary activation function, and $\odot$ the element-wise product of two vectors.
> $$
> y_1=\sigma(W_1x)\odot x,\qquad y_2=\sigma(W_2y_1)\odot x,\qquad z=W_3y_2
> $$
> **(a)** $W_1, W_2, W_3$ are parameter matrices of the block. Assuming the use of bias terms, determine (i) the dimensions of $W_1, W_2, W_3$ and (ii) the number of learnable parameters in this block in terms of $N$ and $D$.
> ```python
> import torch.nn as nn
> class CustomBlock(nn.Module):
>     def __init__(self, N, D, activation_fn):
>         super().__init__()
>         # Complete constructor in Part (b)
>         self.W1 = A
>         self.W2 = B
>         self.W3 = C
>         self.activation = D
>     def forward(self, x):
>         # Implement the forward function in Part (c)
>         return z
> ```
> **(b)** Using the given inputs to the constructor and the `torch.nn.Linear` class, complete `__init__` by stating the lines of code for `A`, `B`, `C` and `D`.
>
> **(c)** Implement the `forward` method to implement $f(x)$.

> [!solution]- Solution
> **(a)(i)** Work from the element-wise products, which need equal lengths. $\sigma(W_1x)\odot x$ forces $W_1x\in\mathbb R^N$, so $W_1\in\mathbb R^{N\times N}$ and $y_1\in\mathbb R^N$. The same argument gives $W_2\in\mathbb R^{N\times N}$ and $y_2\in\mathbb R^N$. Finally $z = W_3y_2\in\mathbb R^D$, so $W_3\in\mathbb R^{D\times N}$.
>
> **(ii)** Each layer has a weight matrix and a bias vector as long as its output:
> $$
> (N\cdot N+N)+(N\cdot N+N)+(D\cdot N+D)=2N^2+2N+ND+D.
> $$
> **(b)** `nn.Linear(in_features, out_features)` (bias is on by default):
> ```python
> self.W1 = nn.Linear(N, N)          # A
> self.W2 = nn.Linear(N, N)          # B
> self.W3 = nn.Linear(N, D)          # C
> self.activation = activation_fn    # D
> ```
> **(c)**
> ```python
> def forward(self, x):
>     y1 = self.activation(self.W1(x)) * x
>     y2 = self.activation(self.W2(y1)) * x
>     z = self.W3(y2)
>     return z
> ```
> `*` between tensors of the same shape is the element-wise product $\odot$. Watch the argument order: the matrix $W_3$ is $D\times N$ (rows = outputs), but the call is `nn.Linear(N, D)` (inputs first). Quick check with $N = 7$, $D = 3$: $56 + 56 + 24 = 136 = 2\cdot49 + 14 + 21 + 3$.

## Problem 4 — A convolutional layer and a max pool (15 pts)

> [!question] Problem 4
> ```python
> import torch.nn as nn
> conv_layer = nn.Conv2d(in_channels=3, out_channels=16, kernel_size=5,
>                        padding=0, stride=1, bias=False)
> ```
> **(a)** Suppose the input to the above layer is a feature map of shape $(H, W) = 40\times40$. What will be the output shape of this convolutional layer?
>
> **(b)** Determine the number of learnable parameters in the above convolutional layer.
>
> **(c)** Consider the below channel of a feature map in a convolutional neural network.
> $$
> Z=\begin{bmatrix}4&1&8&2&3&7\\0&0&2&5&6&5\\1&4&9&2&5&5\\2&6&2&3&3&6\\0&6&6&7&6&3\\6&2&1&1&9&3\end{bmatrix}
> $$
> Suppose we pass $Z$ as input to a max pooling layer with $2\times2$ kernel size and stride 3. Determine the output of this max pooling layer.

> [!solution]- Solution
> **(a)** $H_{out}=\left\lfloor\dfrac{40+2\cdot0-5}{1}\right\rfloor+1=36$, and the same for the width: $(H, W) = 36\times36$, with 16 channels, so the full output is $(16, 36, 36)$.
>
> **(b)** Each of the 16 filters is $3\times5\times5$, and `bias=False`:
> $$
> 16\cdot3\cdot5\cdot5=1{,}200.
> $$
> (With biases it would be $1{,}216$.)
>
> **(c)** Output size $\lfloor(6-2)/3\rfloor+1 = 2$ in each direction. The windows start at rows 0 and 3 and columns 0 and 3:
>
> | window | entries | max |
> |---|---|---|
> | rows 0–1, cols 0–1 | 4, 1, 0, 0 | 4 |
> | rows 0–1, cols 3–4 | 2, 3, 5, 6 | 6 |
> | rows 3–4, cols 0–1 | 2, 6, 0, 6 | 6 |
> | rows 3–4, cols 3–4 | 3, 3, 7, 6 | 7 |
>
> $$
> \begin{bmatrix}4&6\\6&7\end{bmatrix}
> $$
> The stride (3) is larger than the kernel (2), so row 2, row 5, column 2 and column 5 are never looked at; the 9s in the input do not appear in the output.

## Problem 5 — Activations (15 pts)

> [!question] Problem 5
> **(a)** Explain the significance of activation functions to neural networks and why they allow us to build deep networks.
>
> **(b)** Suppose we have an element-wise activation function given by $\mathrm{ReLU}(x) = \max\{0, x\}$ and a mean-pooling operation $g(x)$ of stride 3 with no overlap. Is the below statement true? Please provide justification for your answer.
> $$
> \mathrm{ReLU}(g(x)) = g(\mathrm{ReLU}(x))
> $$
>
> **(c)** **[skipped]** Generative adversarial networks (GANs) are a popular type of deep generative neural network composed of two neural networks: a generator network and a discriminator network. Explain how we train the two networks together. Please be specific about how each model is updated at each training step.

> [!solution]- Solution
> **(a)** The trainable operations in a network (matrix multiplication, convolution) are linear. A composition of linear maps is one linear map, $W_2(W_1x) = (W_2W_1)x$, so without something in between, stacking layers would add nothing. An activation function is a non-linear function placed between the layers; it stops them from collapsing into one, so each added layer can build new features on the previous ones. That is what makes depth useful.
>
> **(b) False.** A counterexample is enough. Take $x = (-2, 3, -1, 0, -3, 6)$; mean pooling with stride 3 averages the two blocks of three.
> $$
> g(x)=(0,\,1)\;\Rightarrow\;\mathrm{ReLU}(g(x))=(0,\,1)
> $$
> $$
> \mathrm{ReLU}(x)=(0,3,0,0,0,6)\;\Rightarrow\;g(\mathrm{ReLU}(x))=(1,\,2)
> $$
> The two sides differ. Reason: ReLU is non-linear, so it does not commute with averaging. Clipping the negatives first removes them from the average; averaging first lets negatives cancel positives.
>
> *Beyond the key:* with **max** pooling the statement would be true. ReLU never reverses the order of two numbers, so the largest entry of a window stays the largest: $\mathrm{ReLU}(\max_i x_i) = \max_i \mathrm{ReLU}(x_i)$.
>
> **(c)** **[skipped]** *Official answer:* at each training step the discriminator receives either a real example from the training set or a fake one produced by the generator, and predicts which it is. The **discriminator is updated to minimize the classification loss**; the **generator is updated to maximize that loss** on the examples it generates.
