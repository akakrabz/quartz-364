## Problem 1 — True or false (30 pts)

> [!question] Problem 1
> Select True or False for each statement.
>
> **(a)** PyTorch `Dataset` classes have three required methods that must be implemented: `__init__`, `__len__` and `forward`.
>
> **(b)** PyTorch `DataLoader` objects allow us to load batches of multiple examples at a time during a training epoch.
>
> **(c)** Momentum in stochastic gradient descent optimizers takes a weighted average of current and previous gradients during update steps.
>
> **(d)** Suppose we have a vocabulary of 64 different words for a text classification model and we encode each word with one-hot encoding. Each encoded vector will be length 8.
>
> **(e)** Consider a learnable embedding module for text data, i.e. `nn.Embedding`. As the vocabulary size increases, we must also increase the dimension of embedded vectors.
>
> **(f)** The "Add & Norm" layers in the original Transformer model use batch norm to normalize activations within the model.
>
> **(g)** Positional encoding helps Transformer models understand the order and relative positions of tokens from an input.
>
> **(h)** Global average pooling in image classification CNN models transforms a shape $(C, H, W)$ collection of feature maps into a length-$C$ vector, where $C$, $H$ and $W$ are the number of channels, height and width of the feature maps.
>
> **(i)** In sequence transduction tasks, an input sequence is transformed into an output sequence. The lengths of the input and output sequences must be the same.
>
> **(j)** Bi-directional RNN layers use the same learnable parameters to process data forwards and backwards in a sequence.

> [!solution]- Solution
> **(a) False.** The third method is `__getitem__`. `forward` belongs to `nn.Module`. → [[4-pytorch-training/datasets-and-dataloaders|Datasets and DataLoaders]]
>
> **(b) True.** That is the DataLoader's job: batching, shuffling and iterating over a `Dataset`.
>
> **(c) True.** With momentum $\mu$ the step uses $v_t = \mu v_{t-1} + g_t$, so every earlier gradient is still in $v_t$ with weight $\mu^k$. → [[4-pytorch-training/optimizers#sgd-with-momentum|SGD with momentum]]
>
> **(d) False.** A one-hot vector has one entry per vocabulary word: length **64**. (8 is $\sqrt{64}$, a distractor; a binary code would need $\log_2 64 = 6$ bits.) → [[7-transformers/text-encodings-and-embeddings#four-encodings-of-the-same-letters|encodings]]
>
> **(e) False.** `nn.Embedding(num_embeddings, embedding_dim)` has two independent arguments. A bigger vocabulary adds rows; the width of each row is your choice. → [[7-transformers/text-encodings-and-embeddings#choosing-the-embedding-dimension|embedding dimension]]
>
> **(f) False.** They use **layer norm**, which normalizes each token's vector by itself and so does not depend on the batch or the sequence length. → [[7-transformers/layer-norm-and-feed-forward#layer-norm-versus-batch-norm|layer norm vs batch norm]]
>
> **(g) True.** Self-attention by itself gives the same result for any ordering of the tokens. → [[7-transformers/positional-encoding|positional encoding]]
>
> **(h) True.** Each of the $C$ maps is averaged over its $H\times W$ entries to one number. → [[5-deep-networks/pooling#the-head-flatten-or-global-pooling|global pooling]]
>
> **(i) False.** The lengths may differ; that is why the decoder generates until `<EOS>`. → [[7-transformers/sequence-to-sequence-rnns|seq2seq]]
>
> **(j) False.** Each direction has its own weights, so the parameter count doubles (checked: `nn.RNN(10, 20, bidirectional=True)` has 1,280 parameters, twice 640). → [[5-deep-networks/bidirectional-and-stacked-rnns|bidirectional RNNs]]

## Problem 2 — Layer shapes and augmentations (17 pts)

> [!question] Problem 2
> The following parts are unrelated.
>
> **(a) (5 pts)** Consider the following code snippet where `X` is an image tensor of shape $(64, 30, 30)$.
> ```python
> import torch.nn as nn
> f = ???
> y = f(X)   # X is shape (64, 30, 30)
> ```
> We would like `y` to be a tensor of shape $(64, 10, 10)$. Which of the following lines of code will produce the desired shape for `y`? (Circle True or False for each option.)
>
> i. `f=nn.Conv2d(64, 64, kernel_size=3, stride=3, padding=1)`
> ii. `f=nn.Conv2d(64, 64, kernel_size=3, stride=3, padding=3)`
> iii. `f=nn.Conv2d(64, 64, kernel_size=1, stride=3, padding=0)`
> iv. `f=nn.MaxPool2d(kernel_size=3, stride=1)`
> v. `f=nn.MaxPool2d(kernel_size=3, stride=3)`
>
> **(b) (12 pts)** Suppose we would like to train CNN models to perform image classification. We are interested in working with two separate datasets:
> - Dataset A: RGB (color) images of different fruits, e.g. blueberries, grapes, lemons, limes.
> - Dataset B: RGB images of individual numbers and English letters from signs, e.g. P, L, 4.
>
> We plan to apply image augmentations while training on each dataset. For each augmentation below, say whether it may be effectively applied to only Dataset A, only Dataset B, both datasets, or neither dataset. Briefly explain your reasoning.
>
> i. Random horizontal (left-right) flipping.
> ii. Random image resizing, i.e. change image size while keeping aspect ratio.
> iii. Color channel shuffling, e.g. change RGB order to BRG.

> [!solution]- Solution
> **(a)** Use $\left\lfloor\dfrac{30 + 2p - K}{s}\right\rfloor + 1$ (it was on the formula sheet). Pooling uses the same formula with $p = 0$.
>
> | | layer | computation | size | answer |
> |---|---|---|---|---|
> | i | conv $K{=}3$, $s{=}3$, $p{=}1$ | $\lfloor 29/3\rfloor + 1$ | 10 | **True** |
> | ii | conv $K{=}3$, $s{=}3$, $p{=}3$ | $\lfloor 33/3\rfloor + 1$ | 12 | **False** |
> | iii | conv $K{=}1$, $s{=}3$, $p{=}0$ | $\lfloor 29/3\rfloor + 1$ | 10 | **True** |
> | iv | max pool $K{=}3$, $s{=}1$ | $\lfloor 27/1\rfloor + 1$ | 28 | **False** |
> | v | max pool $K{=}3$, $s{=}3$ | $\lfloor 27/3\rfloor + 1$ | 10 | **True** |
>
> All five keep 64 channels (the convolutions have `out_channels=64`; pooling never changes the channel count). `X` has no batch dimension, which `nn.Conv2d` and `nn.MaxPool2d` accept: a 3-D input is read as $(C, H, W)$.
>
> **(b)** The test for an augmentation: **does it leave the label unchanged?**
>
> i. **Dataset A only.** A mirrored lemon is still a lemon. A mirrored character can become a different class or no character at all: a flipped "p" looks like "q".
>
> ii. **Both datasets.** Changing the size with the aspect ratio kept changes neither what fruit nor what character is shown.
>
> iii. **Dataset B only.** A character is defined by its shape, so permuting the colour channels does not change its class. Fruits are told apart partly by colour: with shuffled channels a lemon and a lime, or two kinds of berries, become hard to distinguish.

## Problem 3 — A new recurrent layer (15 pts)

> [!question] Problem 3
> Your friend has designed a new recurrent layer that may be used in an RNN. Let the input be $x = \{x_1, x_2, \dots, x_T\}$ for $T$ time steps, where $x_t\in\mathbb R^d$ is the input at time step $t$ and the previous hidden state is $h_{t-1}\in\mathbb R^H$. The new hidden state at time $t$ is computed as follows:
> $$
> z=\tanh(W_x x_t),\qquad h_t=\tanh\big(W_h(z+h_{t-1})\big).
> $$
> $W_x$ and $W_h$ are parameter matrices. Your friend implements the layer as below.
> ```python
> import torch
> import torch.nn as nn
> class FancyNewRNNLayer(nn.Module):
>     def __init__(self, d, H):
>         super().__init__()
>         self.H = H
>         self.tanh = nn.Tanh()
>         self.W_x = nn.Linear(d_1, d_2, bias=False)
>         self.W_h = nn.Linear(d_3, d_4, bias=False)
>     def forward(self, x):
>         T, d = x.size(0), x.size(1)   # x is shape (T, d)
>         h = torch.zeros(self.H)
>         hiddens = []
>         for i in range(T):
>             z = self.tanh(self.W_x(x[i]))
>             h_next = self.tanh(self.W_h(z+h))
>             hiddens.append(h_next)
>         return hiddens
> ```
> **(a) (8 pts)** Determine the values of `d1`, `d2`, `d3` and `d4` in the code and the number of learnable parameters in this recurrent layer in terms of $d$, $H$ and/or $T$.
>
> **(b) (7 pts)** Your friend attempts to train a one-layer RNN model created from the provided code but finds that the model is not effectively learning during training. What is the bug in the implementation, and how can we fix it?

> [!solution]- Solution
> **(a)** Read the sizes off the sum $z + h_{t-1}$, which needs two vectors of the same length. $h_{t-1}\in\mathbb R^H$, so $z = \tanh(W_x x_t)$ must be in $\mathbb R^H$: $W_x$ maps $d\to H$. Then $W_h$ takes that $H$-vector and must return $h_t\in\mathbb R^H$: $H\to H$.
>
> `d1 = d`, `d2 = H`, `d3 = H`, `d4 = H`.
>
> Both layers have `bias=False`, so the count is the two weight matrices:
> $$
> dH + H^2 .
> $$
> $T$ does not appear: the same two matrices are reused at every time step.
>
> **(b)** The loop never updates `h`. Each iteration computes `h_next` from `h`, but `h` stays the all-zeros tensor it was initialized to, so every step computes $\tanh(W_h\tanh(W_x x_t))$ from the current input alone. Nothing is carried from one time step to the next: the layer has no memory.
>
> Fix: add `h = h_next` inside the loop (before or after the `append`).
> ```python
>         for i in range(T):
>             z = self.tanh(self.W_x(x[i]))
>             h_next = self.tanh(self.W_h(z+h))
>             hiddens.append(h_next)
>             h = h_next                  # the missing line
> ```
> *Checked by running both versions with the same weights:* the first output agrees (both start from $h_0 = 0$) and the second already differs. With the bug, changing $x_1$ leaves the output at $t = 4$ unchanged; with the fix it changes.

## Problem 4 — Attention (15 pts)

> [!question] Problem 4
> The following parts are unrelated.
>
> **(a) (6 pts)** Another one of your friends tells you they have created an alternate version of masked attention. For queries $Q\in\mathbb R^{n\times d_k}$, keys $K\in\mathbb R^{n\times d_k}$ and values $V\in\mathbb R^{n\times d_v}$, their new masked attention is
> $$
> \text{NewMaskedAttention}(Q,K,V)=\text{softmax}\!\left(\frac{QK^\top\odot M}{\sqrt{d_k}}\right)V .
> $$
> Here $n$ is the number of tokens, $d_k$ the dimension of each key and query, $d_v$ the value dimension, $\odot$ the element-wise product of two matrices, and $M$ a square masking matrix. When $n = 4$:
> $$
> M=\begin{bmatrix}1&-\infty&-\infty&-\infty\\1&1&-\infty&-\infty\\1&1&1&-\infty\\1&1&1&1\end{bmatrix}
> $$
> Will your friend's new masked attention formula work like the original masked attention? Justify your reasoning.
>
> **(b) (9 pts)** A length-3 sentence $\{w_1, w_2, w_3\} = \{\text{dog}, \text{is}, \text{cute}\}$ is tokenized and embedded by a Transformer model for English-to-Spanish translation and passed to a self-attention block as the following queries $Q$, keys $K$ and values $V$.
> $$
> Q=\begin{bmatrix}3&-1\\2&1\\-1&0\end{bmatrix}\qquad K=\begin{bmatrix}1&1\\-1&-2\\2&-1\end{bmatrix}\qquad V=\begin{bmatrix}2&-2\\4&-1\\1&3\end{bmatrix}
> $$
> Which word does the token "dog" attend to the most in this self-attention block? Show your work.

> [!solution]- Solution
> **(a) No.** The original mask is **added**: a future position gets score $s + (-\infty) = -\infty$ whatever $s$ was, and the softmax turns $-\infty$ into weight 0. Multiplying depends on the **sign** of the score:
>
> | score at a future position | $s\cdot(-\infty)$ | weight after softmax |
> |---|---|---|
> | $s > 0$ | $-\infty$ | 0 (masked, by luck) |
> | $s < 0$ | $+\infty$ | all of it: the future token gets **maximal** weight |
> | $s = 0$ | undefined (NaN) | breaks the row |
>
> So a negative score on a future token flips to $+\infty$, and the token attends to exactly what the mask should hide. (The key's answer is this middle row.) *Run with the matrices of part (b):* the first row of $QK^\top\odot M$ is $(2, +\infty, -\infty)$, and PyTorch's softmax returns NaN for it.
>
> **(b)** Only the scores are needed, and only the row of the query "dog" (token 1):
> $$
> QK^\top=\begin{bmatrix}3&-1\\2&1\\-1&0\end{bmatrix}\begin{bmatrix}1&-1&2\\1&-2&-1\end{bmatrix}=\begin{bmatrix}\mathbf 2&\mathbf{-1}&\mathbf 7\\3&-4&3\\-1&1&-2\end{bmatrix}
> $$
> Row 1 is $(2, -1, 7)$: "dog" scores highest against key 3, so **"dog" attends most to "cute"**.
>
> Two things you do not need: dividing by $\sqrt{d_k}$ and the softmax both keep the order of the scores, and $V$ plays no part in *who attends to whom*. For reference, the weights of row 1 with $\sqrt{d_k} = \sqrt2$ are $(0.028,\ 0.003,\ 0.968)$, and the output for "dog" is that mix of the value rows, $(1.04,\ 2.85)$.

## Problem 5 — MLP, CNN or Vision Transformer? (23 pts)

> [!question] Problem 5
> We would like to train an image classifier for RGB images of size $(C, H, W) = (3, 64, 64)$. Our plan is to compare three different models: multilayer perceptron (MLP), convolutional neural network (CNN) and Vision Transformer (ViT), where each model has multiple layers, i.e. multiple fully connected, convolutional, Transformer encoder layers, respectively.
>
> **(a) (5 pts)** The first layer in the MLP model is given by an `nn.Linear` layer with bias and output dimension 512. Write one line of code that correctly implements this first layer.
>
> **(b) (6 pts)** We choose a token size of $8\times8$ for the ViT model with stride 8. How many tokens will the ViT model take as input from each image, and what is the dimension of each token?
>
> **(c) (6 pts)** After training all three models, we acquire new data where the image sizes are now $(3, 128, 128)$. Which of these models can immediately process these new images without needing to create a new model? (Circle all that apply; brief justifications may help with partial credit.) i. MLP  ii. CNN  iii. ViT
>
> **(d) (6 pts)** Consider pixels at the top-left and bottom-right of an image. Which of these models is capable of expressing interactions between pixels at these corners of the image at its first layer? (Circle all that apply.) i. MLP  ii. CNN  iii. ViT

> [!solution]- Solution
> **(a)** The MLP sees the image flattened to $3\cdot64\cdot64 = 12{,}288$ numbers:
> ```python
> nn.Linear(3*64*64, 512, bias=True)     # bias=True is the default
> ```
> (That one layer has $12{,}288\cdot512 + 512 = 6{,}291{,}968$ parameters.)
>
> **(b)** $64/8 = 8$ patches per side, so $8\cdot8 = $ **64 tokens**. Each token is a flattened $3\times8\times8$ patch: $3\cdot8\cdot8 = $ **192** numbers.
>
> **(c) CNN and ViT.**
> - **MLP: no.** Its first layer is a $512\times12{,}288$ matrix; a $(3, 128, 128)$ image flattens to 49,152 numbers and the multiplication fails.
> - **CNN: yes.** A kernel slides over an input of any size; the feature maps just get larger. (This relies on global pooling before the classifier. A CNN whose head flattens the feature map into an `nn.Linear` would break for the same reason as the MLP.)
> - **ViT: yes.** The same $8\times8$ patches now give $16\cdot16 = 256$ tokens instead of 64, and encoder layers accept any number of tokens. (It needs positional encodings for the extra positions.)
>
> **(d) MLP and ViT.**
> - **MLP: yes.** Every first-layer unit is a weighted sum of **all** pixels, the two corners included.
> - **CNN: no.** A first-layer output sees one $K\times K$ window. The corners meet only in later layers, once the [[5-deep-networks/convolutional-layers#receptive-field|receptive field]] has grown to cover the image.
> - **ViT: yes.** The corners are in two different tokens, and self-attention in the first encoder layer relates every token to every other token.

**Convolution output size**
$$
H_{out}=\left\lfloor\frac{H_{in}+2\times\text{padding}-\text{kernel\_size}}{\text{stride}}+1\right\rfloor,\qquad W_{out}=\left\lfloor\frac{W_{in}+2\times\text{padding}-\text{kernel\_size}}{\text{stride}}+1\right\rfloor
$$

**LSTM**
$$
\begin{aligned}
i_t&=\sigma(W_{ii}x_t+W_{hi}h_{t-1})&&\text{input gate}\\
f_t&=\sigma(W_{if}x_t+W_{hf}h_{t-1})&&\text{forget gate}\\
g_t&=\tanh(W_{ig}x_t+W_{hg}h_{t-1})&&\text{cell gate}\\
o_t&=\sigma(W_{io}x_t+W_{ho}h_{t-1})&&\text{output gate}\\
c_t&=f_t\odot c_{t-1}+i_t\odot g_t&&\text{cell state}\\
h_t&=o_t\odot\tanh(c_t)&&\text{hidden state}
\end{aligned}
$$

**GRU**
$$
\begin{aligned}
r_t&=\sigma(U_rh_{t-1}+W_rx_t)\\
z_t&=\sigma(U_zh_{t-1}+W_zx_t)\\
n_t&=\tanh\big(W_nx_t+r_t\odot(W_hh_{t-1})\big)\\
h_t&=(1-z_t)\odot n_t+z_t\odot h_{t-1}
\end{aligned}
$$
